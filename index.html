About the data

  • Prices, funding, candles, liquidations: Bybit public API (Binance fallback).
  • Catalysts: news feeds read every 15 min by a GitHub Action; an LLM extracts facts only, code does the scoring.
  • Meme tokens: DEX Screener; optional security checks via RugCheck (Solana) and GoPlus (Base) when reachable.
  • Not connected: X/Twitter, on-chain wallet clustering, deployer history, order-book depth, liquidation heatmaps.
Catalysts update automatically from news feeds. Scores are research aids, not profit probabilities. Not financial advice.
